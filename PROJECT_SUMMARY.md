# Project Summary

## Architecture
- **Package**: `com.sece.expert`
- **Framework**: Spring Boot 3.x
- **Data Layer**: Spring Data JPA & Hibernate
- **Database**: H2 In-Memory Database (with MySQL compatibility)

## Modules
1. **Authentication (`/auth`)**: Register and Login for students without JWT or Spring Security.
2. **Student Management (`/student`)**: Complete CRUD operations for students.
3. **Course Management (`/courses`)**: Complete CRUD operations for courses.
4. **Enrollment Management (`/enrollment`)**: Complete CRUD operations for student course enrollments.
5. **Marks Management (`/marks`)**: Complete CRUD operations for student marks and grades.
